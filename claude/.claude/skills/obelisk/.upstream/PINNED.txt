Installed via pnpm global only (/Users/qiushi/Library/pnpm/bin), deliberately:
pnpm's bin directory survives node upgrades where an nvm-scoped npm global does
not. On 2026-08-24 there were briefly two copies -- an npm global at 0.2.5
shadowing a pnpm global still at 0.2.2 -- and a version without --nonce loses
invocation identity silently, so the npm copy was removed rather than kept in
sync. Do not reinstall with `npm install -g`.

Pin the exact version when upgrading: pnpm's packument cache serves a stale
`latest` for a day or so after a release, and `pnpm add -g
@obelisk-apps/cli@latest` installed 0.2.4 while printing "0.2.5 is available".
